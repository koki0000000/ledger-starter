# Ledger Starter

カードの利用通知メールを Gmail で読み、Notion の家計簿に1行足す Google Apps Script。銀行やカード会社のサイトにはログインしない。

対応カードは三井住友・楽天カード・ビューカードの3社。Google Apps Script と Notion だけで動き、月額の費用はかからない。

## 動き

コンビニでカードを使うと、数分後に家計簿に行が増える。

| 日付 | 名前 | 金額 | カード | 分類 |
|---|---|---|---|---|
| 2026-01-15 | コンビニA | ¥1,280 | 三井住友 | 食費 |

Discord の Webhook URL を `Config.gs` に貼ると、記帳のたびに1行通知する。設定しなければ通知なしで動く。

Cloudflare Worker を足すと（`SETUP.md` の手順7）、通知に付いたメニューから分類を選び直せる。選ぶと Notion の行が書き換わり、Discord のメッセージも更新される。

## 同じ買い物を2行にしない

カード会社ごとに通知の届き方が違う。

- 三井住友: 利用の数分後に速報が届く。iD 払いなど速報が来ない利用は数日後の明細で届き、明細には速報済みの利用も混ざる
- 楽天カード: 速報に店名が入らない。数日後の確定版を待って記帳する
- ビューカード: 速報の店名は「国内加盟店」。約1週間後の確報で店名を書き換える

`Code.gs` の大半はこの突き合わせに使っている。

- 処理済みのメールIDを保存し、同じメールを二度読まない
- 三井住友の明細とビューカードの確報は、Notion の既存行を日付と金額で照合してから書く
- 書き込みが1件でも失敗したらその回は止める。速報より先に確報を入れないため

## 使うには

`SETUP.md` の順に進める。記帳だけなら目安30分、Discord のボタンまで入れると45〜55分。コピーと貼り付けだけで、コマンドは打たない。

用意するものは Gmail と Notion のアカウント。Discord のボタンまで入れるなら Discord と Cloudflare のアカウントも要る。いずれも無料の範囲。

取りこぼす条件（外貨、取消と返品、同日同額の2回目など）は `SETUP.md` の「できないこと」にまとめた。

## なぜ Worker が要るか

Google Apps Script の `doPost` が HTTP ヘッダーを受け取れず、Discord が求める署名の検証ができないため。Discord はボタン操作の通知を署名つきの HTTP ヘッダーで送る。Worker が署名を検証し、通った中身だけを GAS へ渡す。

## 確認の範囲

確認済み

- 署名の検証（正しい署名は通り、改ざんと無署名は弾く）
- 3秒以内の応答（実測0.185秒と0.298秒）
- Discord のメニュー操作で Notion の分類が書き換わること

未確認

- 本物の Bot トークンでの投稿が受理されること。GAS から Worker を経て Discord に届くところまでは確認した
- 楽天カードの確定版の記帳と、ビューカードの速報・確報の突き合わせ。Gmail と Notion を実際に繋いで通したのは三井住友だけ

動かないところは issue で。

## 出どころ

自分の家計の自動化から、記帳の部分だけを切り出したもの。明細CSVの照合、領収書の自動取得、家計の集計画面は含まない。
